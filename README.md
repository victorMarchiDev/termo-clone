# 🔤 Termo Clone

Clone fiel do jogo [Termo](https://term.ooo), desenvolvido como exercício prático para a disciplina de Front-End.  
Feito com HTML, CSS e JavaScript, o projeto reproduz a lógica e visual do jogo original, incluindo teclado interativo, validação de palavras e feedback visual por cores.

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3 (estilização manual sem frameworks)
- JavaScript (vanilla)

## 🧠 Como Jogar

1. Tente adivinhar a palavra secreta de 5 letras em até 6 tentativas.
2. Após cada tentativa:
   - 🟩 Verde indica que a letra está na posição correta.
   - 🟨 Amarelo indica que a letra está na palavra, mas em outra posição.
   - ⬛ Cinza indica que a letra não está na palavra.
3. Use o teclado virtual (ou seu próprio teclado) para digitar as letras.
4. Pressione **Enter** para submeter sua tentativa.
5. Use a tecla **←** para apagar uma letra.

## 🧩 Funcionalidades

- Geração aleatória de palavras a cada atualização de página
- Grid interativo com feedback visual
- Teclado dinâmico que muda de cor conforme o progresso
- Compatível com teclado físico e virtual
